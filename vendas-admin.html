Configurar (so uma vez)

1Crie uma senha secreta para o aviso da Kiwify. Toque em "Gerar", copie e guarde.
2Na Vercel (vercel.com → seu projeto → Settings → Environment Variables), crie 3 variaveis:
  • SUPABASE_URL = https://hlygwqftnfmywsmajvkz.supabase.co
  • SUPABASE_SERVICE_ROLE_KEY = no Supabase: Project Settings → API Keys → chave secret (ou service_role). Nunca coloque essa chave em arquivo do GitHub.
  • KIWIFY_SEGREDO = a senha do passo 1
Depois va em Deployments → nos 3 pontinhos do ultimo → Redeploy.
3Na Kiwify: Apps → Webhooks → Criar webhook. Cole o link abaixo, escolha todos os produtos e marque os eventos Compra aprovada, Compra reembolsada e Chargeback.
Depois de salvar, a Kiwify tem um botao para enviar um teste. O teste aparece na aba "Avisos da Kiwify".
4Na area de membros da Kiwify, no modulo de apresentacao (primeira aula), coloque este link com o texto: "Crie agora o seu acesso a plataforma de estudos, usando o mesmo e-mail da compra". Envie o mesmo link para quem pagar por Pix ou Mercado Pago.
5Em Produtos, configure a turma e o prazo de cada produto (aparecem sozinhos depois da primeira venda ou do teste).
